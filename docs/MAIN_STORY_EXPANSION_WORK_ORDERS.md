# 主線擴充工單草案

狀態：等待 Agy 審查。這些工單皆為 `DRAFT`，不可直接執行；應逐張批准、依序實作與驗收。

## 敘事主線

1. **逃離監控網**：既有開場、安全屋與反抗軍脈絡。
2. **解除 01 號檢查哨屏障**：既有目標，改為通往封閉中繼附屬區。
3. **滲透檢查哨中繼附屬區**：既有新內容；取得 125 步偽造簽到憑證與 Citadel 運輸窗口情報。
4. **找出地下運輸線**：由 Relay Slate 05 或 Kira 對話取得；進入 Sub-Sector 0 調查貨運線。
5. **奪取維護通行權**：由受困技師或失事貨艇資訊取得；開啟 Sector 2 維護入口。
6. **破壞製造廠同步器**：由工人日誌或 Zero-One 對話取得；破壞或植入干擾程式。
7. **取得主腦逆轉金鑰**：把三區情報轉為可追溯的終局前置條件。
8. **Citadel 最終抉擇**：保留既有結局命令，但提供完整的因果與缺件回溯。

## 工單執行順序

- [WO-MS-01](work-orders/wo-ms-01.json)：先建立可擴充的發現／任務資料契約。
- [WO-MS-02](work-orders/wo-ms-02.json)：Sector 1 至地下線的動機與線索。
- [WO-MS-03](work-orders/wo-ms-03.json)：地下線的通行權與 Sector 2 入口。
- [WO-MS-04](work-orders/wo-ms-04.json)：Sector 2 同步器主線。
- [WO-MS-05](work-orders/wo-ms-05.json)：Citadel 金鑰收束與終局整合。

## 共通審查原則

- 每個任務必須可由至少一段對話或一份可拾取／可讀取情報首次發現；關鍵任務盡量提供兩條來源。
- 每段都須具備明確的世界內理由、可讀的阻擋回饋與下一步線索。
- 任務系統只能依賴 capability interface，禁止反向依賴 `GameEngine`。
- 每張工單都必須維持公開 API、`TileType[][]` 地圖契約、純 `render()` 與完整回歸測試。
